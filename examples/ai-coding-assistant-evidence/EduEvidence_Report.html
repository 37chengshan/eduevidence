03 Evidence Quality, Counterevidence & Method Audit

Examine why evidence is credible, where it conflicts, and which conclusions require downgrading.

Audit target: overall

Concern
Control GroupMet

All three studies include a no-AI control group.

RandomizationMet

Kazemitabaar 2023 and Bastani 2025 use randomized assignment.

Pre TestMet

Kazemitabaar 2023 has a pre-study evaluation; Bastani 2025 measures baseline covariates.

Post TestMet

Immediate post-tests present in all studies.

Retention TestPartial

Kazemitabaar 2023 has 1-week retention; Bastani 2025 has no delayed test; Marzuki 2024 has delayed test.

Transfer TestPartial

Kazemitabaar 2023 code-modification task is transfer-adjacent; no full no-AI transfer task.

Sample BiasMet

Bastani 2025 nearly 1000 students; Kazemitabaar 2023 small (69) young sample.

Self SelectionPartial

Marzuki 2024 consent-based participation risks self-selection.

Measurement ValidityPartial

Practice/task performance is not equated to learning; independent exams present in Bastani 2025 only.

ConfoundersPartial

Prior programming competency interacts with AI benefit in Kazemitabaar 2023.

Instructor EffectN/A

Kazemitabaar 2023 is self-paced; classroom studies may carry instructor effects.

Novelty EffectPartial

Short interventions likely inflate engagement; none of the studies controlled for novelty.

Tool Version EffectN/A

Single tool versions studied; rapid tool change limits durability.

Ai Usage PolicyPartial

Bastani 2025 explicitly contrasts unguarded vs guardrailed usage policies.

DropoutPartial

Marzuki 2024 reports attrition; others not detailed.

Task vs learning guard:

05 Pilot, Evaluation & Stop Conditions

Validate the pilot with independent learning outcomes and pre-specified stop conditions.

Research question: In a first-year C programming course, does a guardrailed AI coding assistant (explain-only → structured collaboration) improve independent problem solving without increasing AI dependency, compared to no-AI instruction?

Baseline: week-1 no-AI programming quiz (independent problem solving, completion time)

Post test: week-8 no-AI programming quiz (independent problem solving, code quality)

Retention: final exam (week 16) — delayed measure 8 weeks after pilot

Transfer: week-8 novel programming task in a strictly no-AI environment

Process metrics

  • weekly lab completion rate
  • AI usage logs: prompts submitted, copied blocks, reasoning traces
  • help-seeking behavior counts

Learning metrics

  • independent problem solving (no-AI quizzes)
  • code quality rubric
  • retention on final exam
  • transfer task score

Risk metrics

  • AI dependency index (usage without understanding, from reasoning-trace quality)
  • academic integrity violations
  • self-reported over-reliance
  • false confidence (post-quiz confidence vs actual score)

Success threshold: treatment group shows non-inferior independent problem solving (delta within 5%) AND superior or equal retention AND AI dependency index below threshold; if independent problem solving declines >10%, the pilot is judged unsuccessful regardless of task-performance gains.

Analysis plan: pre-registered comparison of treatment vs comparison sections on baseline-adjusted learning metrics (ANCOVA); task-performance metrics reported separately from learning metrics; subgroup analysis by prior programming competency; stop-condition monitoring at weeks 3, 5, 7.
