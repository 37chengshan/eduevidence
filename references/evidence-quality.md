# Evidence Quality（证据质量评估）

## 1. 五维质量框架（每维 0/1/2 分）

每条证据按以下五个维度独立打分，各维得分相加，总分 0–10。

### D1 Study Design（研究设计）

- 2 分：随机对照试验（RCT）或有清晰匹配的准实验，含对照且干预与测量分离。
- 1 分：有对照但非随机（如自然班对照）；或前后测无对照；或仅有单组重复测量。
- 0 分：纯观察 / 调查 / 主观报告 / 无对照的描述性研究。

> 对照缺失时该维至多 0 分，整条证据通常无法支撑因果结论。

### D2 Sample Quality（样本质量）

- 2 分：样本与目标 learner 匹配（如同为本科大一编程入门）、样本量足够（每组 ≥ 30）、报告了基线差异并处理。
- 1 分：样本基本匹配但有偏差（如报名制、自选实验组）、样本量偏小（每组 10–30）。
- 0 分：样本严重不匹配（如用研究生推本科结论）、样本量 < 10、无任何样本描述。

### D3 Measurement Validity（测量有效性）

- 2 分：测量工具已验证（标准量表、标准题型）、前后测等价、评分有规范（如盲评、双人评卷）。
- 1 分：测量合理但未验证（自编题目、自评量表）、评分主观且未盲评。
- 0 分：测量与声称结果不对应（如用满意度代替学习效果）、或测量就是任务表现却被当作学习效果。

> 参考 outcome-taxonomy.md：把 C2 当 C1 测量属于测量无效，D3 记 0 分。

### D4 Temporal Strength（时间强度）

- 2 分：干预 ≥ 8 周，且包含保持测试（retention test）或迁移测试（transfer test）。
- 1 分：干预 2–8 周，有后测但无保持/迁移测量。
- 0 分：单次实验/单课时干预，或只有即时效果无任何后续测量。

### D5 Directness（直接性）

- 2 分：证据的 干预×学习者×课程×工具×结果 与目标 Frame 完全对应（如同是"大一 C 语言 + 代码生成工具 + 独立编程"）。
- 1 分：大致对应但有偏差（不同课程但同难度、不同工具同类型、仅指标相近）。
- 0 分：仅在变量名称上相关（如用"编程课满意度"支撑"编程能力"结论）。

> 直接性越低，外推风险越高，需在结论中明确限定范围（见 applicability-policy.md）。

## 2. 总分与等级

| 总分 | 等级 | 含义 | 使用方式 |
| --- | --- | --- | --- |
| 8–10 | `strong` | 设计、样本、测量、时间、直接性均强 | 可支撑较高置信度的建议 |
| 5–7 | `moderate` | 基本可信但有一两处明显不足 | 可作支持性证据，需限范围 |
| 2–4 | `weak` | 设计或测量存在硬伤 | 仅作参考线索，不单独支撑结论 |
| 0–1 | `very_weak` | 几乎不可用 | 不进入 Evidence Matrix 或仅作"反例提示" |

## 3. 评分示例

### 示例 A：某 RCT，大一 C 语言，Copilot vs 无 AI，8 周，含 4 周保持测试与无 AI 迁移测试

- D1=2（RCT 有对照）；D2=2（每组 45 人、基线匹配）；D3=2（标准题本 + 盲评）；
- D4=2（8 周 + 保持 + 迁移）；D5=2（与目标 Frame 完全对应）。
- **总分 10 = strong**。

### 示例 B：某班用 AI 后"作业提交率上升"，教师自评"教学效果变好"

- D1=0（无对照）；D2=1（一个班 28 人）；D3=0（满意度/提交率当学习效果）；
- D4=0（无保持/迁移测量）；D5=1（班级相似但测量不对应）。
- **总分 1 = very_weak**，不得进入结论。

### 示例 C：某研究用"高中 Python 课 + 代码补全"替代"本科 C 语言"，其余条件一致

- D1=2；D2=2；D3=2；D4=1（只有后测无保持测试）；D5=1（课程与学习者层面有偏差）。
- **总分 8 = strong**，但直接性扣分意味着结论必须限定"对高中 Python 场景强、对本科 C 场景中等"。

## 4. 使用规则（必须遵守）

| 编号 | 内容 |
| --- | --- |
| EQ-01 | 每条证据必须给出五维逐项得分与总分，禁止只给一个模糊的"质量高/低"。 |
| EQ-02 | 任何维度证据不足时记 0 分，禁止用"大概""据经验"补分。 |
| EQ-03 | 总分 < 5 的证据不能单独支撑教学建议；`very_weak` 证据不进 Evidence Matrix。 |
| EQ-04 | 结论的置信度与证据等级联动：`strong` 可给高置信度建议，`moderate` 必须附条件，`weak` 只能给"待验证"。 |
| EQ-05 | 质量评估针对"证据"，不针对"研究作者"；同一研究的不同结论需分别评分。 |
