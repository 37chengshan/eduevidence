# Skeptic Protocol（怀疑者协议）

## 1. 目的

Skeptic 的职责是**找反方**：在正面证据之外主动检索可能推翻或限制结论的证据。
未经 Skeptic 检查的结论一律视为"未定论"。

## 2. 固定 9 项任务（每次分析必须全部执行）

Skeptic 对候选结论逐项执行以下 9 个任务，每项输出 `找到 / 未找到` + 证据。

| 编号 | 任务 | 具体内容 |
| --- | --- | --- |
| S-01 | 找 null result（无效结果） | 检索同类型干预报告"无显著差异"的研究，如"AI 辅助 vs 无 AI 下成绩无差异"。 |
| S-02 | 找 negative result（负面结果） | 检索"效果更差"的研究，如"使用 AI 后独立解题能力反而下降"。 |
| S-03 | 找相反方向研究 | 检索结论方向与当前结论相反的研究，如主流结论是"允许"，找"禁止/受限更好"的证据。 |
| S-04 | Alternative explanation（替代解释） | 对正面结果提出至少 2 种替代解释（练习量、教师投入、新鲜感、额外辅导），并检查原研究是否排除。 |
| S-05 | Measurement mismatch（测量错配） | 检查正面结论的测量是否与宣称 Outcome 错配（把 C2 当 C1、满意度当学习效果）。 |
| S-06 | Sampling bias（抽样偏差） | 检查样本是否偏向高动机/高先验人群，是否存在自选实验组。 |
| S-07 | Novelty effect（新奇效应） | 检查正面效果是否可能来自工具新鲜感，而非持续学习收益。 |
| S-08 | AI dependency（AI 依赖） | 检索工具撤除后表现下降的证据，检查正面研究是否报告了无 AI 条件的迁移测试。 |
| S-09 | 结论超出研究范围 | 检查原结论是否超出了证据的 学习者×课程×工具×时长×情境 范围。 |

## 3. 反方证据来源要求

- **反方证据必须来自真实文献、真实研究报告或真实数据。**
- 禁止虚构、编造、推测性的"可能存在的反方证据"。
- 若依据的是个人经验或推理，必须标注 `来源=推理`，并单独列为"假设性反驳"，
  不得与文献证据混同。

## 4. 无反方证据时的输出

当全部 9 项任务均未找到有效反方证据时，**必须逐字输出**：

```
NO CONTRADICTORY EVIDENCE FOUND
```

该语句是唯一合法的"无反驳"输出；禁止用"似乎没问题""应该没反例"等模糊表述代替。

## 5. 输出格式

### 每个任务的输出

```
S-01 null result    : 找到 / 未找到
证据: <文献标题/作者/年份 + 关键结果一句话>
影响: <对候选结论的具体限制，或"无影响">
```

### 汇总输出

```
候选结论: <一句话>
Skeptic 汇总:
  - 找到反方证据的任务: S-xx, S-yy
  - 反方证据强度: 强（可推翻）/ 中（需限范围）/ 弱（提示作用）
  - 未找到的任务: S-zz, ...
  - 结论: NO CONTRADICTORY EVIDENCE FOUND
        | 存在反方证据，候选结论需修改或限定为: ...
```

## 6. 执行规则（必须遵守）

| 编号 | 内容 |
| --- | --- |
| SK-01 | 9 项任务缺一不可；缺项则 Skeptic 报告不完整，裁判庭不得使用。 |
| SK-02 | 虚构反方证据属于严重违规；发现即废弃该 Skeptic 报告并重新执行。 |
| SK-03 | 假设性反驳（推理来源）必须单独列出，不得算作"找到反方证据"。 |
| SK-04 | 某任务找到多条证据时按证据质量（evidence-quality.md）排序，只取最高质量的 2 条。 |
| SK-05 | 反方证据即使与候选结论方向相反，也需完成方法学审查（methodology-audit.md）后才能纳入裁判。 |
| SK-06 | 无证据输出必须使用固定字符串 `NO CONTRADICTORY EVIDENCE FOUND`。 |

## 7. 示例

> 候选结论：允许 Copilot 辅助的大一 C 语言班作业正确率更高，说明 AI 提升学习效果。

```
S-01 null result   : 找到。Lee et al. (2024) 报告代码补全组与对照组
                     在期末闭卷成绩上无显著差异（p=0.42）。
S-02 negative result: 未找到。
S-03 相反方向      : 找到。Yuan (2025) 报告无 AI 提示组在迁移测试显著优于全自动补全组。
S-04 替代解释      : 找到。原研究未排除"实验班课后多花 2 小时/周"的练习量差异。
S-05 measurement   : 找到。原研究用"作业正确率(C2)"得出"学习效果(C1)"结论，错配。
S-06 sampling bias : 未找到。
S-07 novelty       : 找到。干预仅 4 周，存在新鲜感解释空间。
S-08 AI dependency : 找到。原研究未提供撤除 AI 后的独立测试数据。
S-09 超出范围      : 找到。原研究样本为研究生，被用来支撑本科生结论。

Skeptic 汇总: 存在中强反方证据。候选结论需改写为：
  "AI 辅助可提高 AI 环境下的作业完成表现，但无证据表明提升学习效果；
  存在迁移下降与依赖风险，且原证据有测量错配与样本外推问题。"
```
