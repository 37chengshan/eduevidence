# Methodology Audit（方法学审查清单）

## 1. 最高优先级规则

```
任务完成表现不能自动等价为学习效果
```

**Rule：** 任何研究若仅以"AI 辅助下的任务完成度/正确率/速度"作为判断学习效果的依据，
该证据的方法学权重直接下调一档，且结论只能表述为"任务表现改善"，不得表述为"学习效果改善"。
审查结果中此项单独标注 `HIGH-PRIORITY-VIOLATION` 或 `HIGH-PRIORITY-PASS`。

## 2. 审查项清单

对每条证据逐项审查，每项给出 `通过 / 未通过 / 不适用` + 证据摘录 + 对结论的影响。

### 2.1 实验设计类

| 审查项 | 审查问题 | 通过标准 |
| --- | --- | --- |
| `control_group` | 有无对照组？对照组是否接受等量教学时间？ | 有对照且时间/作业量平衡 |
| `randomization` | 分组是否随机？是否为自选/报名？ | 随机或准随机；自选视为失败 |
| `pre_test` | 是否测量了干预前基线？ | 有前测且报告基线可比性 |
| `post_test` | 是否有干预后即时测量？ | 有标准化后测 |
| `retention_test` | 是否有延迟保持测量（≥ 2 周）？ | 有；缺失则时间强度降档 |
| `transfer_test` | 是否有无 AI / 新情境迁移测量？ | 有；缺失则无法支持迁移结论 |

### 2.2 样本类

| 审查项 | 审查问题 | 通过标准 |
| --- | --- | --- |
| `sample_bias` | 样本是否代表目标 learner？ | 教育层次/专业/先验知识与目标一致 |
| `self_selection` | 参与者是否自行选择组别？ | 无自选；自选需报告动机差异并做敏感性分析 |

### 2.3 测量类

| 审查项 | 审查问题 | 通过标准 |
| --- | --- | --- |
| `measurement_validity` | 测量是否真的测到了声称的 Outcome（见 outcome-taxonomy.md）？ | 指标与结论对应；未把 C2 当 C1 |

### 2.4 混淆因素类

| 审查项 | 审查问题 | 通过标准 |
| --- | --- | --- |
| `confounders` | 有无变量同时影响干预与结果（如课外补习、作业时间差异）？ | 识别并控制/统计调整 |
| `instructor_effect` | 干预与教师是否绑定？不同班是否不同教师？ | 教师交叉或教师效应已分析 |
| `novelty_effect` | 新工具带来的短期新鲜感是否可能解释效果？ | 干预 ≥ 8 周 或 有反实验期 |
| `tool_version_effect` | 工具版本是否固定并报告？ | 指定版本与配置 |
| `ai_usage_policy` | 学生实际使用方式是否符合规定的 allowed_usage？ | 有日志/抽查，确认无未授权使用 |

### 2.5 完整性类

| 审查项 | 审查问题 | 通过标准 |
| --- | --- | --- |
| `dropout` | 流失率与流失原因？流失是否与组别相关？ | 流失率报告且两组可比较；否则结果有偏 |

## 3. 审查输出格式

每项固定输出三行：

```
项: control_group
判定: 通过 | 未通过 | 不适用
依据: <原文证据摘录 + 原文页码/段落>
影响: <对结论置信度的具体影响，如"对照组时间不平衡，效应可能来自练习量而非 AI">
```

## 4. 综合判定规则

| 编号 | 规则 | 后果 |
| --- | --- | --- |
| MA-01 | 缺失 `control_group` 或 `randomization` 中的任意一项 | 因果结论降级为相关/描述性结论 |
| MA-02 | 缺失 `retention_test` | 禁止声称"长期保持" |
| MA-03 | 缺失 `transfer_test` | 禁止声称"迁移能力"或"无 AI 时也能胜任" |
| MA-04 | `sample_bias` 或 `self_selection` 未通过 | 外推时必须在 applicability 中标注"样本自选，存在动机偏差" |
| MA-05 | `measurement_validity` 未通过且属于"把 C2 当 C1" | 触发 HIGH-PRIORITY-VIOLATION，结论只能谈任务表现 |
| MA-06 | `novelty_effect` 未排除 | 效果时间衰减假设，推广前需更长试点 |
| MA-07 | `tool_version_effect` 未报告版本 | 结论限定"该版本"或降置信度 |
| MA-08 | `ai_usage_policy` 未核查实际使用 | 结论限定"按规范使用的前提下" |
| MA-09 | `dropout` 未报告或两组不平衡 | 视为存在系统性流失，可能高估效果 |

## 5. 审查示例

> 某研究声称"允许 Copilot 的班级作业成绩显著更高，故 AI 提高学习效果"。

```
control_group   : 通过（有平行班）
randomization   : 未通过（实验班为教师主动报名）
pre_test        : 未通过（未做前测，无法排除基线差异）
post_test       : 通过（期末统一试卷）
retention_test  : 未通过（无延迟测量）
transfer_test   : 未通过（考试即平时作业变体，且考场允许 AI）
measurement_validity: 未通过（作业成绩=AI 辅助任务表现 C2，被当作学习效果 C1）
                 → HIGH-PRIORITY-VIOLATION
confounders     : 未通过（未报告课外使用 AI 时长）
novelty_effect  : 未通过（干预仅 4 周）
tool_version_effect: 通过（固定 Copilot 版本）
ai_usage_policy : 未通过（无使用日志）
dropout         : 未报告

综合：仅能得出"在自选报名、无前测、允许 AI 考试的情况下，作业成绩更高"这一
受限描述；禁止得出"AI 提高学习效果"。建议重做 RCT 并补保持/迁移测量。
```
