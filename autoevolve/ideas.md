# Autoevolve Ideas

Use this file for candidate hypotheses that have not yet been run. Keep each idea falsifiable and scoped to one main change.

Template:

```text
## IDEA-...
Observation:
Hypothesis:
Mutable surface:
Expected measurable gain:
Possible regression:
Required evaluator:
```

Do not copy failed ideas back here unchanged; connect them to the experiment ID that changed the hypothesis.
