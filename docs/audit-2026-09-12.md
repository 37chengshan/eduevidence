## 修复主线：域注册表成为唯一权威

约 40 项共享一个根因：domains/<id>/outcome_taxonomy.json 里每个 token 已带 category，
但代码硬编码了一份教育映射并带 .get(token, learning) 兜底。注册表是死的、代码是活的，
于是 policy 域无法完成、报告分组塌缩、缺口诊断失真、迁移强制教育分类。

修复后：engine/taxonomy.py 是唯一读取者；未知 token 抛错（fail closed）；
scripts/check_protocol_alignment.py 断言 schema 枚举 == 注册表并集，任何漂移即门失败。

## 本轮工程教训（记录，不追责）

1. 只读审计的溢出部分必须全部读回：审计员把超出摘要上限的条目写进 /tmp，
   第一次汇报只覆盖摘要里的部分，遗漏过半。清单落盘到本文即为修正。
2. 测试不 assert 等于没有测试：红队套件跑了很久、打印了很多 BUG FOUND，
   但它永远不会失败。补上断言的当场就抓出一个真缺陷。
3. 契约必须与生产者核对：report_spec、chart-spec 的 schema 描述的是没人产出的形状，
   于是有 schema 变成了账面安全。
