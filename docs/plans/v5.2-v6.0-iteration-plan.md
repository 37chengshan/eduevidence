# EduEvidence v5.2 → v6.0 版本迭代计划

> 制定日期：2026-08-24。依据：当日三维审查（代码库健康度、七维度批判性审查、外部竞品与趋势调研）。
> 本文件替代 `docs/v4-roadmap.md` 成为唯一路线图；v4-roadmap 30 项中多项"已实施"标注与本计划附录 A 的证据不符，后续状态以本目录 `STATUS.md` 为准。

## 决策记录（2026-08-24 用户拍板）

1. **未来 1–2 个月主目标 = 开源社区发布**：补齐"跑自己的问题"的上手路径、工程地基、CI 三件套，然后推广。
2. **伪造示例处置 = 真实文献重建**：用经核验的真实 DOI 重建旗舰示例，不硬凑规模；合成产物若保留必须显著标注。

## 总原则

- 先可信度 → 再地基 → 后能力；没有可信示例之前不做任何推广动作。
- 每个版本定义**最小可发布子集**与验收门；工作量用人日区间表达（单人节奏），不设日历承诺。
- 大件（E2/E3）可拆为 x.y.z 补丁独立发布，避免冲刺式烂尾。

## 版本锚点

当前版本口径混乱（详见附录 A-3）。治理决定：

- **versions.py 为唯一版本权威**；`engine/__init__.py:7` 的死值 `ENGINE_VERSION = "2.0.0"` 修复或移除。
- 新增 `scripts/check_version_consistency.py`：校验 versions.py ↔ pyproject.toml ↔ CHANGELOG 头条目一致，纳入 CI。
- 下一版本号定为 **5.2.0**（沿用 CHANGELOG 时间线，不重置，避免制造第 6 个口径）。

## 附录 A：审查证据（2026-08-24，文件路径均可复核）

### A-1 致命问题 Top5

1. **旗舰示例数据为随机生成**：`scripts/build_killer_demo.py:137-204` 以 `random.seed(42)+random.uniform` 逐条生成 50 篇"研究"的效应量/CI/p 值/样本量，`study_design` 由 `idx % 2` 决定（:198）；"+0.64g vs −0.28g" 为脚本硬编码（:213,224）。DOI 伪造实证：`:33` 给 Bastani 配 `10.1073/pnas.2412345122`（Crossref 404；正确 DOI 2422633122 就在同仓 `examples/ai-coding-assistant/sources.jsonl`）；`:34` 的 `10.1145/3544548.3581388` 解析为他人论文。而 `CHANGELOG.md:43` 称"50 篇真实学术文献"、`SKILL.md:97` 与 `web/landing.html:109` 以此为卖点；烘焙报告无任何 synthetic 披露；且已进 `upload/examples/` 提交包。
2. **运行 provenance 造假**：`examples/esl-academic-writing-ai/result.json:5-21` 与数学示例声明 `mode=agent_mcp_enhanced`+8 agents，实为 `scripts/generate_new_projects.py` / `build_esl_artifacts.py` 手工构造；抽查 ESL `10.125/llt.2024.08`、数学 `10.1016/j.compedu.2025.104920` 均 Crossref 404。
3. **指标与版本口径失控**：测试数 4 口径（610+ @docs/install-guide.md:76 与 v4-roadmap.md:48；682@README.md:315；703@CHANGELOG.md:65；实际 749 函数/74 文件）；schema 数 3 口径（13/33/37，实际 37）；版本号 5 口径（`engine/__init__.py:7`=2.0.0、pyproject=4.0.0、`engine/versions.py:7`=5.0.0、SKILL.md=5.0.0、CHANGELOG=5.1.0）；references 11(README.md:301) vs 实际 15 文件；金标题数 10(README.md:233) vs 实际 30。
4. **可复现性承诺超出兑现**：docs/reproducibility.md:3 承诺"全新环境复现"，但无 seed 固定（仅 build_killer_demo.py:137 有）、无依赖 lockfile、empirical 依赖外部模型 API（run-empirical-01/manifest.json 仅 temperature:0.0）。
5. **产品定位落差**：`scripts/orchestrator.py:21-25` 自述本地仅执行 adjudicate/present 两阶段，其余 7 阶段留给外部 agent 且无随附驱动器；README Usage 8 条命令全部操作预置示例；landing 页 Skill #650 外链指向他人 skill。

### A-2 工程健康事实（好的方面）

749 测试函数/74 文件；SSRF 防护完整（retrieval/validate.py:55-80）；meta_analysis/robustness 教科书级实现（缺精度不猜 se、D3=0 剔除、leave-one-out）；CI 三作业设计认真；基准体系最扎实（30 题金标入库、B0-B4、双评估器）；核心零第三方运行时依赖。

### A-3 工程债要点

sys.path 注入 ≥10 处；build_report.py 3496 行（模板/CSS 内嵌 Python）；生成 HTML 入库致重烘焙大 diff；web 四副本无同步机制；三代 benchmark harness 并存；Studio CDN 依赖与报告 zero-JS 标准不一；TODO 计数为 0 的假象（债以多代并存形式累积）；curl|bash 无 pin；检索层无 robots/限速/paywall 政策；全库无日志。
